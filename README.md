# Описание проекта
Этот проект представляет собой сайт туристического агенства "Kessirass", состоящий из клиентского приложения для пользователей и административной панели для управления контентом. Проект разделен на три основные части:

admin-panel/ - Административная панель для управления контентом сайта (турами, заявками, командой)

client-app/ - Клиентское приложение для пользователей (каталог туров, информация о команде, форма заявок)

ui-library/ - Библиотека переиспользуемых UI-компонентов

## Технологический стек
### Runtime зависимости
- react ^19.2.0 - UI библиотека
- react-dom ^19.2.0 - Рендеринг React
- react-router-dom ^7.9.6 - Маршрутизация
- @my-app/ui-library * - Локальные UI-компоненты
#### Dev зависимости
- typescript ~5.9.3 - Статическая типизация
- vite ^7.1.11 - Сборщик и dev-сервер
- eslint ^9.36.0 - Линтинг кода
- jest ^30.2.0 - Тестирование

## Компоненты библиотеки
### 1. PhotoGallery
- Адаптивная галерея фотографий:
- Плиточное отображение
- Обрезка длинных подписей
- Адаптивное количество колонок
- Fallback при ошибках загрузки
### 2. ProductCard
- Карточка товара(тура):
- Фоновая картинка
- Гибкое позиционирование текста (слева/справа)
- Кнопка действия
- Градиентный оверлей для читаемости
### 3. Banner
- Главный баннер страницы с фоновым изображением:
- Заголовок и подзаголовок
- Список преимуществ/особенностей
- Адаптивные кнопки с плавными переходами
### 4. Card
- Универсальный контейнер для контента:
- Содержит заголовок, два описания и фото
- Поддержка различных вариантов использования (вертикаль и горизонталь)
### 5. ContactCard
- Карточка контактов с ссылками на соцсети:
- Прямые ссылки для связи на соцсети (WhatsApp, Telegram, VK и бота в Telegram)
### 6. Form
- Форма для подачи заявок:
- Поля: Имя (обязательное) и Телефон (с валидацией)
- Сообщение об успешной отправке
### 7. TeamCard
- Карточка сотрудника команды
- Фотография сотрудника с квадратным соотношением сторон
- Информация: ФИО, должность, описание

## Инструкция по запуску
1. Клонирование репозитория
```
git clone < repository-url >
cd project
```
2. Установка зависимостей и запуск UI Library
```
cd ui-library
npm install
npm run build
```
3. Запуск приложений
```
cd ../client-app
npm install
npm run dev
```
и 
```
cd ../admin-panel
npm install
npm run dev
```
4. Открытие в браузере

Приложение client-app будет доступно по адресу: http://localhost:5173
Приложение admin-panel будет доступно по адресу: http://localhost:5174

## Скрипты проекта
### Для проектов admin-panel, client-app и ui-library
- npm run build - сборка библиотеки (ui-library)
- npm run dev - разработка с вотчером
- npm run test - запуск тестов
- npm run lint - проверка кодстайла
- npm run test:coverage - запуск тестов с генерацией отчета о покрытии кода

## Тестирование
```
cd ui-library
npm run lint
npm run test
npm run test:coverage
```

```
cd ../frontend
npm run lint
npm run test
npm run test:coverage
```
